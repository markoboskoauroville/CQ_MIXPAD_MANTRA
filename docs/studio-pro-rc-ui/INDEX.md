# Fender Studio Pro Remote (com.presonus.dawremote, "Studio Pro RC"), 9.11.2026

Pulled from the Nothing Phone over adb (APK and splits), installed only in the Mantra Sandbox, run in its Demo mode.
01-08 intro slides (Home, Mix Page, Plug-in Editor, Macro Page, Commands Page, Performance Page), 10-14 demo Mix page and its views.

Worth borrowing:
- Left rail of view switches (Fader / Inserts / Sends / Cue mix, and Channels / Inputs / Outputs) as big flat buttons: one tap changes what every strip shows (we could do Main / Out1-6 / FX the same way).
- Strip = coloured header band per channel group, M / S side by side, pan above, fader with a wide light cap and the meter in its own column left of the groove, name tab coloured at the bottom.
- Pinch to zoom the time line / swipe to move: same gestures as ours.
- Corner buttons (undo/redo, transport) on a bottom bar, always reachable by thumb.
- Demo mode on the start screen: a way to try the interface without a mixer (our CQ mode could get one).
